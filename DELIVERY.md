# jobbot landing pages

Three landing pages served by the local dashboard (`jobbot/dashboard.py`).
Start the server with `python3 run_dashboard.py`, then:

| Route | Design | Source of truth |
|---|---|---|
| http://127.0.0.1:8765/landing | Maximalist spray-paint, solid colours, no gradients | original |
| http://127.0.0.1:8765/landing2 | Clone of teardwn.com collage | `.ref/teardwn.html` |
| http://127.0.0.1:8765/landing3 | Clone of vestris.ai | `.ref/vestris.html` |

## Layout

- `templates/landing*.html` — one self-contained file per page (inline CSS/JS, Google Fonts via `<link>`).
- `jobbot/static/landing2/img/` — 68 collage assets (32 MB).
- `jobbot/static/landing3/` — 4 painted illustrations (sky, bee, stamp, countryside).
- `jobbot/static/landing1/` — empty; all texture is generated by inline SVG filters.
- `.ref/` — reference captures and QA screenshots. Gitignored; safe to delete.

Routes live in `Handler.do_GET`; assets are served by `Dash.serve_static`, whose
mime map covers css/js/png/jpg/jpeg/gif/webp/avif/svg/woff/woff2/mp4.

## Verified

Measured against a running server, not asserted:

- All three routes return 200.
- 48 referenced `/static/` URLs, 0 broken. 0 console errors, 0 failed requests.
- No horizontal scroll at 1440 or 390 (`window.scrollX` stays 0 after `scrollTo(9999,0)`).
- landing2 document height is 8981px at 1440 — an exact match to the reference.
  Stage scaling is exact: 65 of 68 rendered text leaves scale by 0.6500 at 390px
  (the 3 others are `<title>`, `<style>` and a meta string, none rendered).
- landing3 computed values match the live reference: body `#F2EFE5`,
  button `rgb(98,101,78)`, card/panel radius 20px, pill radius 4px,
  hero `96px/105.6px/-2.88px`.
- No reference-brand strings remain in either clone; 0 CSS gradients in landing1.

## Deliberate deviations

- **landing2** keeps the reference's generic collage textures and pop-culture gag
  cutouts, but every recognisable photo of a real person from the source site is
  replaced with an abstract SVG stand-in. `NationalPark-Variable` is substituted
  with the Google font `National Park`.
- **landing2** adds a white pill behind the "your job hunt needs an operator"
  label. The reference has no pill; without it the label was illegible against
  the paint.
- **landing3** uses the reference's painted artwork (sky, bee, stamp,
  countryside) because that artwork is the design's identity. The product
  mockups — browser frame and iMessage phone — are rebuilt in HTML/CSS showing
  jobbot's own UI, since the reference's screenshots show a different product.
  Copy is original, written to the same beats, not word-swapped.
- **landing3** nav is a hamburger-triggered dropdown at every breakpoint, which
  is what the live reference actually does.

These pages reproduce two third-party designs closely, including landing3's
artwork. That is fine for a localhost dashboard. Do not publish them.
